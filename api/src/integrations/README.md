# 外部サービス連携

配送・決済・メールなどを追加するクエストでは、連携先ごとにディレクトリを作る。たとえば配送追跡なら `delivery-tracking/delivery-tracking.client.ts` が外部 API と通信し、`modules/shipping/` が対象注文の権限と配送状態の扱いを決める。

- クライアントは外部サービスの URL・認証・タイムアウト・応答の検証を担当する。業務側へ渡す値は外部サービスのレスポンス形式から変換する
- API キーは環境変数から取得する。キーや利用者の個人情報はログや課題リポジトリに含めない
- 注文や在庫のトランザクション中に外部の応答を待たない。連携を含む課題では再送とタイムアウト時の扱いを決める
- 採点ではテスト用の応答で成功と失敗を再現する。課題が採用する外部サービスとテスト方法は課題文に記載する
